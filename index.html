MERN Authentication System Architecture

Overview & Design Rationale

This system serves as a scalable boilerplate and authentication foundation for production MERN web applications. It enforces state-of-the-art cryptographic safeguards to preserve user credentials and prevent unauthorized endpoint access.

Key Architecture Highlights

01. Signup & Encryption

User submits credentials. Password is salted with 10 bcrypt salt rounds and hashed prior to MongoDB persistence.

02. Login & Token Grant

Bcrypt comparison verifies credentials against database hash. Signed JWT is minted containing user payload & expiry.

03. Route Protection

Express middleware intercepts incoming requests, verifies Bearer token validity via jwt.verify, and attaches authenticated user to req.user.

04. React Context Sync

Client application stores token in memory/HTTP-only cookies and synchronizes auth state across protected views.

API Endpoint Specifications

Method Endpoint Access Description
POST /api/auth/register Public Validates user data, hashes password, creates document
POST /api/auth/login Public Validates credentials, returns JWT token & user profile
GET /api/auth/profile Protected Retrieves authenticated user profile via JWT Bearer header
